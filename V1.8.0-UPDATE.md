# Nexa AI v1.8.0 - Native Visual Review Pipeline

This update replaces the failed Build 106.x post-build patch approach.

## Active runtime

`package.json` now uses `main-v180.js` as the Electron main entry.
The v1.8 entry loads the verified v1.7 core, applies the reviewed image-generation corrections in memory, then executes that patched core as the real application runtime.

The visual evaluator is therefore part of the application startup path. It is not an optional installer that can be skipped after compilation.

## Visual pipeline

User image request
-> Nexa prompt planner
-> deterministic visual constraints
-> ComfyUI render
-> save temporary result
-> Qwen2.5-VL:3b receives the actual PNG as Base64
-> structured visual evaluation
-> Nexa deterministic scoring and critical-error checks
-> targeted prompt repair
-> retry up to 3 attempts
-> select best evaluated result

## Fail-visible behavior

If Qwen2.5-VL:3b is missing or Ollama cannot run it, v1.8 does not silently claim the image was visually approved. The generation reports a clear local error instead.

During a working generation the user must see progress text similar to:

- Nexa Visual: comprobando Qwen2.5-VL 3B
- Nexa Visual: llamando Qwen2.5-VL 3B
- Nexa Visual APROBO ... or Nexa Visual rechazo ... reparando

A persistent JSON-lines trace is written to:

`D:\LocalAI\NexaAI\Data\visual-evaluator-v180.log`

A successful review contains `qwen_call_start` followed by `qwen_review_complete`.

## Quality corrections included

- Fixes the old `car` substring bug that could treat `cartoon` as a car request and force landscape resolution.
- Explicit close framing is normalized to 896x896.
- Explicit full body is normalized to 768x1024.
- Removes `character concept art` and similar positive prompt terms that can produce character sheets.
- Blocks character sheet, turnaround, reference sheet, lineup, multiple views, multiple poses and contact sheet.
- Detects `canguro`, `kanguro` and `kangaroo`.
- A single kangaroo request is treated as exactly one subject.
- Adds strong kangaroo identity cues before the first render, not only after failure.
- Keeps explicit red boxing gloves, pose, style and framing as reviewable requirements.
- Qwen is instructed that anthropomorphic animals are allowed; it must not invent a rule against anthropomorphism.
- Wrong subject count, wrong species, wrong explicit style, missing mandatory attribute, wrong pose, wrong framing and character-sheet output are critical failures.

## Hardware policy

Qwen visual review runs with `num_gpu: 0` initially. ComfyUI resources are released before visual review. This keeps the GTX 1070 Ti VRAM focused on image generation rather than loading another visual model on the GPU.
