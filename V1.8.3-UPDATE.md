# Nexa AI v1.8.3 Update

## Qué cambia
1. Se elimina cualquier timeout duro del pipeline de revisión visual.
2. Se reemplaza el corte por tiempo por un sistema de estado y heartbeat.
3. Si un intento tarda mucho, Nexa sigue informando el estado en vez de abortar.
4. Solo se aborta por cancelación manual o error real.
5. Se guarda un archivo de estado para saber si Qwen fue llamado.

## Política nueva
- No auto-abort por tiempo.
- MaxVisualAttempts sigue vigente (por defecto 3).
- Render y review reportan estado continuamente.
- Si hay progreso, Nexa sigue esperando.
- Si no hay progreso, Nexa NO mata automáticamente; solo marca estado STALLED para el usuario.

## Archivo de estado
Se recomienda escribir:
D:\LocalAI\NexaAI\Data\visual-status-v183.json

Campos sugeridos:
- requestId
- attempt
- phase
- status
- startedAt
- updatedAt
- message
- qwenCalled
- qwenReviewed
- score
- accepted
- errors
