# Nexa AI v1.9.0 Update

## Funciones nuevas

### 1) Chat Attachments
El chat acepta:
- drag & drop
- botón de cargar archivo
- pegar desde portapapeles

Tipos soportados inicialmente:
- imágenes: png, jpg, jpeg, webp
- documentos: pdf, txt, md, docx

### 2) Vision Intake
Si el mensaje lleva imagen, Nexa puede:
- describirla
- responder preguntas sobre ella
- compararla con otra imagen
- usarla como referencia visual

### 3) Reference Images · Parecido y Consistencia
Si el usuario escribe frases como:
- parecido a esta imagen
- usa esta imagen de referencia
- el mismo perro
- same dog
- same style
- similar to this

y hay una imagen adjunta, Nexa la envía también al motor de referencias.

### 4) Copy / Paste natural
El usuario puede:
- pegar una imagen capturada
- pegar texto largo
- pegar varias cosas seguidas
sin aprender comandos.

## Flujo recomendado
Mensaje del usuario + adjuntos
↓
Message Attachment Intake
↓
clasificar adjuntos
↓
si imagen + petición de parecido → Reference Engine
si imagen + pregunta visual → Qwen Vision
si documento → Text Extract / Context
↓
Prompt Compiler / respuesta / generación
