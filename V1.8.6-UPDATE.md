# Nexa AI v1.8.6 Update

## Aplicado en esta versión

### 1) Soft Review Decision Engine
Antes, varios campos `uncertain` se convertían en errores casi como si fueran `fail`.
Ahora la decisión se divide así:

- **Hard**: obliga a retry
- **Soft**: baja score, pero no obliga retry
- **Uncertain**: pequeña penalización, nunca crítica por sí sola

### 2) Threshold recomendado
- `visualAcceptThreshold = 78`
- `visualGreatThreshold = 88`

### 3) Reference Images Panel
Se añade soporte para carga de referencias.

Campos sugeridos:
- `enabled`
- `mode`
- `strength`
- `identityWeight`
- `styleWeight`
- `compositionWeight`
- `useInRetries`
- `carryBestApprovedAnchor`
- `maxReferences`

### 4) Política de retries
No reintentar si solo fallan checks suaves.
Reintentar únicamente si existe hard failure o score realmente bajo.

### 5) Casos ideales
- Crear versiones parecidas del mismo perrito
- Mantener un personaje consistente entre imágenes
- Usar una foto o render como base de parecido
- Mantener estilo de una imagen de referencia
