Los trabajos en Web v2 usan developer.ai.generate y herramientas developer.* que ya

prepara operaciones y laboratorios locales adicionales para futuras mejoras WEB.

CONECTAR LA COPIA SIN DESCONECTAR LA WEB ORIGINAL (OPCIONAL)
Si el Nexa Windows actual sigue unido a la página original y quieres mantenerla,
puedes añadir una segunda conexión OPCIONAL en el archivo local HostedWeb/agent.json.
Necesitas conocer la URL HTTPS real de la COPIA y el token real emitido por ella.
Conserva las claves originales 'serverUrl' y 'agentToken'; añade:
  "developerWebServerUrl": "https://DOMINIO-REAL-DE-LA-COPIA/RUTA-BASE",
  "developerWebAgentToken": "TOKEN-REAL-DE-LA-COPIA"
No reemplaces el JSON entero, y no publiques el token. Reinicia Nexa Windows después.
El conector secundario solo se inicia cuando HTTPS, URL distinta y token de al menos
20 caracteres se verifican; en caso contrario el agente original sigue como antes.
No es necesaria una recompilación para cambiar estas direcciones/tokens.

LIMITACIONES HONESTAS
- No se ha ejecutado Qwen en la GPU del usuario ni instalado el EXE en su Windows.
- El Developer Web v2 actual edita SOBRE TODO copias importadas a Hostinger y utiliza
  herramientas de Windows para lectura/inspección. El protocolo Windows v3 ya ofrece
  laboratorios locales; la interfaz Web v2 NO expone todavía todos esos comandos nuevos.
  Futuras ampliaciones de esa interfaz podrán usar el protocolo estable sin EXE nuevo.
- Las comprobaciones PHP requieren PHP CLI EN WINDOWS para el laboratorio local;
  si no existe, el estado debe indicar 'no verificado'. Web tiene su parser propio.
- SQLite en Windows permite inspección a través de developer.db.inspect cuando el
  Runtime lo soporta; migraciones en el proyecto original no se habilitan aquí.
- Las pruebas funcionales de cualquier proyecto no se pueden certificar solo con
  50 pruebas unitarias del agente. Deben ejecutarse en copia real y con dependencias.
- Los límites locales de permisos, rutas y ejecución son controles de seguridad
  necesarios. Los parámetros normales de orquestación permanecen controlados en la web.
- Este ZIP es overlay de FUENTES para el repositorio y App Builder Pro; no es EXE
  independiente ni contiene el resto del repositorio, que ya existe en GitHub.
